# Lexico — тренажер англійських слів

Офлайн PWA для вивчення слів за алгоритмом інтервального повторення SM-2.
Без сервера, без збірки, без залежностей. Дані живуть у IndexedDB на твоєму пристрої.

## Як запустити

Service worker і встановлення на телефон потребують `http://`, а не `file://`,
тому запускай через локальний сервер:

```sh
cd vocab
python3 -m http.server 8777
```

Далі відкрий `http://localhost:8777`.

**На телефон:** щоб відкрити з телефона в тій же Wi-Fi мережі, дізнайся IP
комп'ютера (`ipconfig getifaddr en0` на macOS) і зайди на `http://<IP>:8777`.
У Safari: «Поділитися» → «На екран Home». У Chrome: меню → «Встановити додаток».
Після встановлення працює повністю офлайн.

## Тижневий цикл

Вкладка **«Сьогодні»** — це план дня, а не просто черга карток.

**Понеділок–субота — дні навчання.** Щодня видається 30 нових слів плюс усі
повторення, час яких настав. Норму змінюєш прямо на екрані «Сьогодні» —
кнопки 10 / 20 / 30 / 50 під планом, діє відразу. На екрані
видно кільце прогресу, скільки нових зроблено з норми, скільки повторень
лишилось, і смугу тижня з результатом кожного дня.

**Неділя — підсумок.** Нових слів немає. Замість них — перевірка **всіх слів,
вивчених з понеділка по суботу**. У кінці видно, скільки з них ти памʼятаєш
упевнено, і список тих, що забулися; вони автоматично повертаються в
повторення найближчими днями.

Дні до твого першого заняття не рахуються пропущеними — смуга тижня починає
рахувати пропуски лише з дня, коли ти справді почав.

Норма нових слів виконується завжди. Налаштування «Максимум повторень за
сесію» обмежує лише повторення, щоб велика норма не витіснила їх із черги.

**Інтервальне повторення.** Оцінок дві: **«Знаю»** і **«Не знаю»**. «Знаю» —
інтервал зростає (1 → 3 → 7 → 17 → 43 днів…). «Не знаю» — слово скидається на
початок і повертається ще в цій же сесії. Швидкість росту підлаштовується під
тебе: кожна вдала відповідь трохи піднімає множник (стеля 2.8), кожна помилка
опускає (підлога 1.4). Під кнопкою «Знаю» написано, коли слово зʼявиться
наступного разу.

**Режими перевірки** вибираються автоматично за зрілістю слова:

| Повторень | Режим |
|---|---|
| 0 (нове) | картка з перевертанням (EN → UA) |
| 1–2 | картка або вибір з 4 варіантів |
| 3+ | введення слова руками (UA → EN) або вибір варіанта |

Введення приймає одну-дві опечатки (відстань Левенштейна), щоб не карати за
дрібницю.

**Звук вимкнений за замовчуванням.** Озвучка працює через вбудований у браузер
синтез мови, а системні голоси сильно різняться за якістю й часто звучать погано.
Увімкнути можна в «Налаштування» → «Звук і озвучка слів» — перемикач діє відразу,
без кнопки «Зберегти». Поки звук вимкнений, кнопки 🔊 приховані, щоб не було
мертвих елементів інтерфейсу.

Картку можна перевернути натисканням прямо по ній — вона обертається в 3D,
показуючи переклад, приклад і саме слово.

**Гарячі клавіші під час повторення:** `Пробіл` — показати відповідь,
`1` — не знаю, `2` — знаю.

## Перший запуск

На порожньому словнику екран «Сьогодні» пропонує одну дію — «Завантажити
1000 слів». Кнопка бере готовий набір, додає найчастотніші слова і одразу
починає сесію, нічого шукати по вкладках не треба. Коли слова вже є, той самий
екран перемикається на звичайний стан «На сьогодні все» з кнопкою
«Повторити наперед».

## Про інтерфейс

Візуально зроблено в дусі Quizlet: світла тема, індиго-акцент `#4255ff`,
великі картки з м'якими тінями, «натискні» кнопки з темнішою нижньою кромкою
і геометричний шрифт. Темна тема вмикається автоматично за системною.

Шрифти системні (`Avenir Next` та аналоги) — жодного зовнішнього запиту,
інакше б зламався офлайн-режим. Висота картки адаптується під екран
(`clamp(280px, 44vh, 420px)`), щоб на високих телефонах не було порожнечі.
Для тих, хто вимкнув анімації в системі, перевертання вимикається автоматично
через `prefers-reduced-motion`.

**Після оновлення дизайну обов'язково перезавантаж сторінку жорстко**
(`Cmd+Shift+R`) — service worker інакше віддасть стару версію стилів із кешу.

## Готовий набір: 5646 слів

Вкладка «Додати» → «Готовий набір». Можна завантажити 300, 1000, 2500 або всі
слова, і обмежити рівнями (наприклад лише A1–A2). Слова додаються строго за
частотністю, тому перші картки — це найуживаніша лексика. Власні слова завжди
йдуть у черзі перед набором.

Завантаження 5646 слів не завалить тебе повтореннями: усі вони стають «новими»,
а в чергу щодня потрапляє лише стільки, скільки стоїть у налаштуванні «Нових слів
на день» (за замовчуванням 30, понеділок–субота).

**Як набір зібрано.** Порядок слів — з частотного списку англійських субтитрів
(OpenSubtitles через `hermitdave/FrequencyWords`), бо субтитри відображають живу
розмовну мову, а не мову вебсайтів. Переклади, транскрипція, частина мови та
приклади речень — з англійської Wiktionary через її API. Відсіяно службові слова,
словоформи (`said`, `going`, `came`), власні назви, абревіатури та записи без
українського перекладу.

Покриття: транскрипція у 5583 слів (98,9%), приклад речення — у 4170 (74%).
Переклад прикладів порожній — його можна догенерувати через AI-автозаповнення.

**Чого очікувати від якості.** Переклад беруть з першого смислового блоку статті
Wiktionary, тобто для основного значення. Для багатозначних слів це іноді не те
значення, яке потрібне: наприклад `need` подано як «нужда», хоча частіше потрібне
«потребувати». Такі картки правляться вручну за кілька секунд. Рівні A1–C2 виведені
з частотності, а не з офіційних списків CEFR, тож це орієнтир, а не сертифікація.

**Джерела та ліцензії.** Wiktionary — CC BY-SA 3.0; частотний список
`hermitdave/FrequencyWords` — CC BY-SA 4.0. Якщо будеш публікувати додаток,
збережи цю атрибуцію (вона вже є у вкладці «Готовий набір»).

## AI-автозаповнення (опційно)

У Налаштуваннях можна вписати ключ Anthropic API. Тоді:

- кнопка **✨ AI** у формі додавання заповнює переклад, транскрипцію, частину мови,
  приклад речення з перекладом, рівень і теми за одним лише словом;
- у масовому імпорті галочка «Доповнити через Claude» робить те саме для всього
  списку порціями по 15 слів.

Запити йдуть напряму з браузера в `api.anthropic.com` з заголовком
`anthropic-dangerous-direct-browser-access`, модель за замовчуванням —
`claude-opus-4-8`, відповідь приходить як структурований JSON за схемою
(`output_config.format`), тому парсинг надійний.

Ключ зберігається тільки локально і **не потрапляє в експорт**. Оскільки він
лежить у браузері, не використовуй ключ із широкими правами — заведи окремий
із мінімальним лімітом витрат. Без ключа весь інший функціонал працює як є.

## Дані

Експорт/імпорт JSON у Налаштуваннях — це твій бекап. Імпорт пропускає слова,
які вже є, і зберігає прогрес повторень з файлу. Дані не синхронізуються між
пристроями: телефон і ПК ведуть окремі словники, переносити — через експорт.

## Структура

```
index.html             розмітка всіх екранів
app.css                стилі, світла й темна тема
app.js                 IndexedDB, SM-2, режими перевірки, Claude API
seed.json              готовий набір на 5646 слів (1,1 МБ)
sw.js                  офлайн-кеш (підніми CACHE при зміні файлів)
manifest.webmanifest   метадані PWA
icon.svg               іконка
```

`seed.json` навмисно не кешується під час встановлення PWA — він підтягується
в кеш лише коли ти справді завантажуєш набір, щоб перше встановлення було швидким.
